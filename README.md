# Engineering Standards Playbook

A practical engineering leadership playbook covering delivery standards, Agile practices, flow metrics, team governance, and scalable software delivery.

This repository is intended to demonstrate engineering leadership approach, not commercial source code.

## Focus Areas

- Engineering leadership and team management
- Agile / SCRUM operating model
- Flow metrics: cycle time, throughput, WIP
- Delivery predictability and release governance
- Azure / .NET engineering standards
- AI adoption across the SDLC
- Quality engineering and code review standards
- Observability, reliability, and operational maturity
- Onshore, nearshore, and offshore team collaboration

## Why This Matters

In large engineering organisations, delivery performance depends on clear standards, strong technical leadership, measurable flow, and consistent execution across multiple teams.
